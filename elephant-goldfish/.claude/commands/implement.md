## 执行步骤

### 步骤 1：加载护栏

```
⚙️ 实施模式已激活

加载设计文档作为护栏...

📄 文档：docs/FEATURE_NAME.md
📋 需要修改的文件：[从文档第3节提取列表]

规则：
- 严格遵循设计文档
- 不得添加文档未提及的功能
- 不得修改文档未列出的文件
- 如发现文档与实际代码不符，暂停并向用户报告
```

### 步骤 2：逐文件实施

按照文档中列出的文件顺序，逐一实施。每个文件完成后：

```
✅ 已完成：path/to/file.py
   - 修改内容：[简短描述]
   - 符合文档：是/否（如否，说明原因）

下一个文件：path/to/next.py
是否继续？
```

### 步骤 3：偏离检测

如果实施过程中发现需要偏离文档：

```
⚠️ 发现文档偏离

原因：[具体说明]
建议：
  选项A：按文档实施（可能有以下问题：[说明]）
  选项B：更新文档以反映实际情况（推荐）
  选项C：重新设计这部分

请指示如何处理。
```

**不得静默偏离文档。任何偏离都必须向用户报告并获得确认。**

### 步骤 4：上下文丢失恢复

如果会话中断，新会话可以快速恢复：

```
提示词模板：
"阅读 docs/FEATURE_NAME.md。阅读其中引用的所有文件。
告诉我我们的实施进度，然后继续。"
```

### 步骤 5：实施完成

所有文件实施完成后：

```
⚙️ 实施完成

已修改文件：
- [列表]

已创建文件：
- [列表]

→ 请运行 /code-review 进行代码评审
```

## 注意事项

- 实施期间如果 AI "跑偏"（幻觉），启动新会话，输入设计文档即可立即恢复
- 代码必须严格遵循文档，这是防止技术债的核心机制
- 每个文件完成后更新 `claude-progress.md`
