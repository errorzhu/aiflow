# /done — 会话结束清单 / Session Wrap-up Checklist

## 📝 会话结束协议

**触发时机**：每次会话即将结束时

---

## 执行步骤

### 步骤 1：进度盘点

回顾本次会话，列出：

```
📋 本次会话完成情况：

✅ 已完成：
- [任务1]
- [任务2]

🔄 进行中（下次继续）：
- [任务1] — 当前状态：[具体说明]

❌ 未完成（原因）：
- [任务1] — 阻塞原因：[说明]
```

### 步骤 2：更新 feature_list.json

检查并更新当前功能的状态字段：
- `status`：根据当前阶段更新
- `goldfish_tests`：更新已通过的测试
- `human_approved`：如果已获得人工审批

### 步骤 3：更新 claude-progress.md

在文件顶部（最新的在最上方）添加新的会话记录：

```markdown
## 会话 XXX — YYYY-MM-DD

**日期**：YYYY-MM-DD  
**状态**：[进行中/已完成]  
**当前功能**：[F00X - 功能名称]  
**当前阶段**：[🐘设计/📄文档/🐟金鱼/⚙️实施/✅完成]  

**已完成**：
- [任务列表]

**下一步**：
1. [具体的下一个行动]
2. [具体的下一个行动]

**重要决策记录**：
- [如有重要决策，在此记录]

**备注**：[其他需要记住的信息]
```

### 步骤 4：下次会话恢复提示

```
💡 下次会话恢复提示词：

"阅读 CLAUDE.md、claude-progress.md、feature_list.json，
以及 docs/[当前功能].md（如果存在）。
告诉我我们上次的进度，然后继续。"

复制以上提示词，下次会话开始时使用它。
```

### 步骤 5：最终确认

```
✅ 会话结束清单完成

- claude-progress.md：已更新
- feature_list.json：已更新
- 下次恢复提示词：已准备

下次会话可以在 30 秒内恢复到当前状态。
```

---

## 注意事项

- **不要跳过此步骤**。更新进度日志是大象模型的核心机制
- 花 5 分钟更新文档，节省下次会话 30 分钟的上下文重建时间
- 如果会话因为上下文长度被迫中断，也要尽可能完成此步骤
